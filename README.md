# מערכת רפואה קהילתית (הדגמה)

מערכת מקיפה לניהול רפואה בקהילה בסגנון קופת חולים: רופאים, מרשמים, בית מרקחת ומטופלים.
**כל הנתונים פיקטיביים. המערכת היא להדגמה ולימוד בלבד ואינה מיועדת לשימוש קליני.**

## הפעלה

אין צורך בהתקנה. אפשר לפתוח את `index.html` ישירות בדפדפן, או להריץ שרת מקומי:

```bash
npm start          # http://localhost:8080
npm test           # בדיקות ללוגיקה הקלינית
```

## מה יש במערכת

### רופא/ה
- **יומן תורים יומי**: סימון "הגיע/ה" ו"הסתיים", מעבר מהיר לתיק.
- **חיפוש מטופלים** לפי ת.ז, שם או טלפון, וקליטת מטופל חדש עם אימות ספרת ביקורת של ת.ז.
- **תיק רפואי**: אלרגיות, מחלות רקע, תרופות פעילות, ביקורים, מרשמים, הפניות ותורים.
- **תיעוד ביקור**: תלונה, מדדים, ממצאים, אבחנה ותוכנית טיפול.
- **מרשם ממוחשב** עם בדיקת בטיחות בזמן אמת:
  - אלרגיות ורגישות צולבת (למשל פניצילין וצפלוספורינים).
  - אינטראקציות בין תרופות, גם מול תרופות שהמטופל כבר נוטל.
  - כפילות טיפולית והגבלות גיל.
  - אזהרה חמורה חוסמת את המרשם עד לאישור מפורש ונימוק קליני, שנרשם ביומן.
  - מרשם כרוני עם ניפוקים חוזרים, ותוקף מקוצר (10 ימים, ללא חזרות) לסמים מסוכנים.
  - השתתפות עצמית משוערת לפי סל הבריאות והביטוח המשלים.
- **הפניות** למומחים, **אישורי מחלה** והדפסת מרשם.

### בית מרקחת
- איתור מרשמים לפי ת.ז, ניפוק מלא או חלקי, וניפוק מכמה מרשמים בפעולה אחת.
- חסימת ניפוק למרשם שבוטל או שפג תוקפו, כשאין מספיק מלאי, או כשניפוק חוזר מוקדם מ-25 יום.
- חובת אימות זהות לפני ניפוק סם מסוכן.
- חישוב השתתפות עצמית וקבלה להדפסה.
- ניהול מלאי עם התראות על מלאי נמוך או שאזל, והיסטוריית ניפוקים.

### מטופל/ת
- אזור אישי: תורים קרובים, מרשמים פעילים, ביקורים והפניות.
- זימון תור לפי רופא, תאריך ושעה פנויה, וביטול תור.

### מנהל/ת
- לוח בקרה עם נתונים מרכזיים, ניהול משתמשים, יומן פעולות (Audit), איפוס וייצוא נתונים.

## מבנה הקוד

```
index.html          נקודת כניסה (RTL)
css/styles.css      עיצוב (כולל מצב כהה, מובייל והדפסה)
js/clinical.js      לוגיקה קלינית טהורה: אלרגיות, אינטראקציות, השתתפות עצמית, סטטוס מרשם
js/data.js          נתוני הדגמה: תרופות, אינטראקציות, משתמשים ומטופלים
js/store.js         שמירה ב-localStorage ויומן פעולות
js/app.js           ממשק המשתמש לכל התפקידים
tests/              בדיקות יחידה (node:test)
```

הנתונים נשמרים ב-`localStorage` של הדפדפן. לחיבור למערכת אמיתית יש להחליף את `store.js` ב-API מול שרת ומסד נתונים, ולהוסיף אימות משתמשים מאובטח, הצפנה ועמידה בדרישות פרטיות המידע הרפואי.
